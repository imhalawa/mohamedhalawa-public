Obsidian

A folder of Markdown files, a short list of starting points and links between notes.

Mohamed Halawa/22 Nov 2026

What made me stay with Obsidian was the file format. A note is a Markdown file in a folder on my machine. I can open it in another editor and keep working. That matters when the same folder holds years of reading notes, debugging observations and decisions.

I keep the top level fairly flat. An unfinished idea goes in Inbox. A source I want to revisit goes in Sources. Home contains notes that point into a subject. A link can connect a decision to the reference behind it without requiring me to file them both in the same place.

If that sounds like a useful way to work, the vault structure is the part of my setup I’d start with. The full write-up also covers capture, daily notes and the plugins I use.
