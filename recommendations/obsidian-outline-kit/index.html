Three pieces for an Obsidian outline

Two plugins and a CSS snippet for moving through a note one branch at a time.

Mohamed Halawa/22 Nov 2026

In April I documented an Obsidian setup for a specific task. I wanted to move a bullet together with its children, focus on that branch and find my way back to the full note. Each piece handles a different part of the interaction.

  1. Move the branch. Outliner makes list items easier to move, indent and fold. Install it first to give the outline its editing behavior. Outliner
  2. Focus on one item. Zoom narrows the view to a bullet and its descendants. The breadcrumb at the top takes you back out. It also works on headings. Zoom
  3. See which bullet is active. My optional CSS snippet adds a ring on hover and uses the accent color for the selected bullet. It helps distinguish the item you’re about to click in a deep outline. Bullet styling snippet

The original walkthrough includes the plugin settings and explains where to put the snippet.
