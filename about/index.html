About

Mohamed Halawa

I’m Mohamed Halawa. I build open-source tools and write about the decisions inside them. A lot of the work starts with something I want to be able to do myself, like follow a change after it ships or move a whole branch of notes with the keyboard.

Roamer brings outlining to Obsidian while keeping the notes in plain Markdown. TechJobsNL tracks vacancies at selected Dutch employers and lets you trace a skill count back to the postings behind it. With on-my-watch, I can keep an eye on a Datadog query beside the code I’m working on.

This site is where I can give one decision more room than it gets in a README. Each piece links to the project or change it describes, so you can look at the same code and draw your own conclusions.
