Recommendations

I keep notes on the books I’m working through and how I set up my tools. These picks come from those notes.

  • Book review

    Grokking Algorithms

    Bhargava draws each algorithm before showing the code. The grid in the dynamic programming chapter finally helped me see how one answer leads to the next.

  • Tool

    Obsidian

    I stayed with Obsidian because each note is a Markdown file I can open in any editor. I keep the folders flat and use links to connect ideas across them.

  • List

    Three pieces for an Obsidian outline

    Outliner moves a bullet with its children, Zoom focuses on that branch, and a small CSS change marks the active bullet. Together they make a deep outline easier to edit.

  • Tool

    herdr

    After trying tmux and Zellij, I settled on herdr. I can use the mouse and keyboard habits I already have, which leaves more of my attention for the task in the terminal.
